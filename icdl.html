Welcome to the Basic Computer Skills course!

This 8-week course is designed for complete beginners who want to become confident computer users. No previous experience is required. Throughout the course, you will learn the essential skills needed for studying, office work, and everyday computer use.

    By the end of the course, you will be able to:

  • Use a computer confidently and understand its basic components.
  • Organize files and folders efficiently.
  • Create professional documents using Microsoft Word.
  • Design clear and engaging presentations with Microsoft PowerPoint.
  • Perform calculations and organize data using Microsoft Excel.
  • Collaborate online using Google Workspace, including Google Drive, Docs, Sheets, Slides, Gmail, and Forms.
  • Apply digital skills to real-life tasks in education and the workplace.

Weekly Lesson Plan:

Week 1

Computer Essential

Topics:

  • file managment: Create folders, files, desktop shortcuts, and learn keyboard shortcuts.
  • internet & online essential: browser, search, email, and online safety.
  • Typing Master intro

Hands-on practice:

  1. Typing Master practice
  2. Create a folder by your name and three files named Word , PowerPoint , and Excel. And craete a shortcut for the folder.
  3. open your browser , create 3 tabs , and boookmark a learning site
  4. create a free email account and send to yourself a test email.

Week 2

Microsoft Word

Topics:

  • Text format and style
  • Tables
  • Shapes
  • Images
  • Headers and Footers
  • Page setup
  • Printing

Hands-on practice:

  1. Write a one-page about your favorite field document in Word and save it as PDF.
  2. open new document insert table, shape and image for practice.

Week 3

Microsoft PowerPoint

Topics:

  • Slide layouts
  • Themes
  • insert: Picture, Shape, and Video
  • Transitions
  • Animations
  • Slide Show
  • View and Review

Hands-on practice:

  1. Create 5 slides presentation about your favorite topic.
  2. Add transitions and animations.
  3. Add images or video about the topic

Week 4

Microsoft Excel

Topics:

  • Worksheets
  • Formatting
  • Tables
  • Functions
  • Sorting & filtering
  • Formulas
  • Data
  • Charts

    • Hands-on practice:

    1. Create a student grade sheet.
    2. Use SUM, AVERAGE, MIN, MAX, COUNT.
    3. Create a column chart.
    4. Sort students by score.

    Week 5

    Microsoft Outlook & OneNote

    Topics:

    • Create a Microsoft acccount
    • Outlook email
    • Calendar
    • OneDrive managment
    • OneNote

    Hands-on practice:

    1. Send a professional email.
    2. Schedule a meeting in Calendar.
    3. Upload and share a file from OneDrive to Outlook email.
    4. Create a notebook in OneNote with notes and images.

    Week 6

    Google Workspace

    Topics:

  • Google Drive
  • Gooogle Forms
  • Team collaboration
  • Google Docs
  • Google Slides
  • Google sheets
  • Google Calendar

    • Hands-on practice:

    1. Create a document in Google Docs.
    2. Build a budget table in Google Sheets.
    3. Make a short presentation in Google Slides.
    4. Create a 5-question quiz in Google Forms.
    5. Share all files through Google Drive.
    6. Collaborate with your classmate and edit the same document

    Week 7

    Review

    • Typing master practice
    • Create a folder named Review Week with three subfolders named docs , slides , and sheets.
    • Write a one-page document in Word
    • Create an Excel table with five students and use the function if for coloring pass or faill
    • Make a 3-slide PowerPoint presentation
    • Upload all files to Google Drive.
    • Share one file with your classmate.
    • Send an email with the shared file attached or linked.
    • Create a 3-question Google Form.
    • Identify essential keyboard shortcuts.

    [ difficult topics wil be repeated for more practice ]

    Week 8

    Final Project & Exam

  • Organize files into one folder named "Exam-yourname" with subfolders named Microsoft office and Google Workspace
  • Create a professional CV , export the document as a PDF , and save it on Microsoft office subfolder.
  • Prepare a PowerPoint presentation then present it in the class
  • Save and share files using Google Drive.
  • Create a Google Form survey.
  • Using Outlook, attach all your completed work to an email and send it to the facilitator.

    • Note: An extra week will be used if the students cannot finish the course within the planned eight weeks. Depending on the number of hours allocated to the course each week, up to two additional weeks may be required.
